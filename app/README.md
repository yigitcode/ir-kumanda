# IR Kumanda — Android uygulaması

Proje açıklaması, tuş kodları ve derleme adımları için kök dizindeki [README](../README.md) dosyasına bakın.

```sh
flutter test
flutter build apk --release
```

Ekran görüntülerini yeniden üretmek için:

```sh
SCREENSHOT_DIR=../docs/screenshots FONT_DIR=$FLUTTER_ROOT/bin/cache/artifacts/material_fonts flutter test test/screenshots_test.dart
```
